# Rekonstrukcja Instrukcji Obsługi: Husqvarna Automatic Klasa 21 (Broszura 56 Stron)

Pomyślnie zrekonstruowano i opublikowano pełny, fabryczny podręcznik użytkownika (**Operating Manual for Viking Automatic home sewing machine class 21**) w oryginalnym formacie **poziomej broszury A5 (56 stron)**. 

Dokument ma charakter prawdziwej, profesjonalnie złożonej publikacji cyfrowej (wektorowy tekst z możliwością wyszukiwania, elegancka typografia, brak szumów i zabrudzeń skanu) z zachowaniem wszystkich 64 oryginalnych rycin, tabel oraz rozkładówek.

## 🌟 Najważniejsze cechy zrealizowanego dokumentu

1. **Wierne odwzorowanie formatu broszury (1:1):**
   - Geometria `@page { size: 210mm 148mm; margin: 0; }` odpowiada dokładnie fabrycznemu formatowi książeczki Husqvarny.
   - Dokładnie **56 stron**, w tym strona tytułowa, przedmowa, spis wyposażenia, 45 stron instrukcji i ściegów, gwarancja, tylna okładka oraz 4-stronicowa rozkładówka referencyjna (**Foldout Schematics**).

2. **Czysta, wektorowa typografia i skład:**
   - Wykorzystano czcionki zbliżone do oryginalnych szwedzkich krojów bezszeryfowych (*Liberation Sans / Inter*).
   - Ponad **8 200 słów** w pełni przeszukiwalnego i edytowalnego tekstu w języku angielskim.
   - Usunięto wszelkie odręczne dopiski, cienie skanera i plamy.

3. **Kompletna baza 64 ilustracji:**
   - Wszystkie rysunki techniczne, zdjęcia akcesoriów, schematy nawlekania, wzorniki krzywek automatycznych (A, B, C, D), obszywanie dziurek, reperacje i konserwacja zostały wykadrowane i wyczyszczone.
   - Ryciny smarowania (Fig. 63, 64, 65, 66) oraz schematy maszyny (Fig. 1 i Fig. 2) pochodzą bezpośrednio z anglojęzycznych materiałów fabrycznych z angielskimi oznaczeniami.

4. **Integracja z repozytorium GitHub:**
   - Wszystkie pliki źródłowe HTML, ryciny w katalogu `images_manual_en/` oraz skompilowany plik PDF zostały zsynchronizowane i wypchnięte do repozytorium [husqvarna-21-manuals](file:///home/qba/Dokumenty/husqvarna-21-manuals).
